# Tarefas — dev-frontend — launcher-tv

UI React + TS + Vite em `ui/`, rodando no WebView2. Camadas da seção 2a da arquitetura: componentes em `features/*/components` e `shared/ui`, stores Zustand em `features/*/store.ts` e `app/navigation`, IPC só em `shared/ipc`. A marca vem de `docs/brand/sofa/` por alias `@brand`, sem cópia.
